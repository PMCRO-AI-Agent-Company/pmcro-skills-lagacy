# Resume Order

Use this order whenever resuming a repository session.

1. Resolve the repository root before asking for it.
2. Make one read-only filesystem check before writes.
3. Read the repository's declared entry-point documents in their
   documented order.
4. Inspect pending work before starting a new task.
5. Follow the repository's numbered resume checklist top-to-bottom.
6. Record verification evidence and any newly discovered blockers.

Do not substitute this reference for the repository's actual
instructions. If the repository defines a different entry-point set,
follow those files after locating them.
