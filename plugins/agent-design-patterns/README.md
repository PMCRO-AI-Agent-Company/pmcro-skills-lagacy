# agent-design-patterns

Composable agent design patterns based on Anthropic's published architecture
guidance. These skills describe orchestration strategies; they do not mandate
a runtime or framework.

## Patterns

`augmented-llm` · `prompt-chaining` · `routing` · `parallelization` ·
`orchestrator-workers` · `evaluator-optimizer` · `agent-loop`

Use the smallest pattern that improves measurable task quality. Keep
boundaries explicit, validate intermediate results, and increase autonomy only
when the task requires it.
