# Routing

Use routing when multiple specialists or execution paths exist and the task
must be classified before work begins.

## Workflow

1. Define input classes and success conditions.
2. Select the smallest suitable specialist for each class.
3. Keep routing and specialist contracts explicit.
4. Validate routing decisions at deterministic boundaries.
5. Measure quality, latency, cost, and risk before adding complexity.

## Support

- `references/pattern.md` contains selection guidance.
- `assets/example.md.template` is an implementation skeleton.
- `scripts/validate-pattern.ps1` validates the package.
